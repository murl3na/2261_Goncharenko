### Задание 3 **(2)**

*Напишите пример программы на* **Java** *с двумя вложенными циклами и инструкцией* **break** *для выхода
из двух вложенных циклов. В качестве такой программы можно взять поиск первого нуля в двумерном массиве.*

```
public class BreakDemo {
    public static void main(String[] args) {
        int[][] matrix = {
            {1, 2, 3},
            {4, 0, 6},
            {7, 8, 9}
        };
        int zeroRow = -1;
        int zeroCol = -1;
        outerLoop:
        for (int i = 0; i < matrix.length; i++) {
            for (int j = 0; j < matrix[i].length; j++) {
                if (matrix[i][j] == 0) {
                    zeroRow = i;
                    zeroCol = j;
                    break outerLoop; 
                }
            }
        }
        if (zeroRow != -1) {
            System.out.println("Первый ноль найден на позиции: [" + zeroRow + "][" + zeroCol + "]");
        } else {
            System.out.println("Нулей в массиве нет.");
        }
    }
}
```

### Задание 5 **(2)**

*Напишите программу на С++, которая прочитает натуральное число* **n**, *создаст вектор
из* **n** *элементов, прочитает значения элементов, добавит последний элемент вектора к каждому элементу 
(в том числе и к последнему), найдет и выведет количество положительных и отрицательных элементов вектора
после изменения. Из циклов в программе можно использовать только циклы по коллекции.*

```
#include <iostream>
#include <vector>

int main() {
    int n;
    std::cin >> n;
    std::vector<int> vec(n);
    for (int i = 0; i < n; ++i) {
        std::cin >> vec[i];
    }

    int last_elem = vec.back();
    for (int &elem : vec) {
        elem += last_elem;
    }
    int positive_count = 0;
    int negative_count = 0;
    for (int elem : vec) {
        if (elem > 0) {
            positive_count++;
        } else if (elem < 0) {
            negative_count++;
        }
    }
    std::cout << "Положительных: " << positive_count << "\n";
    std::cout << "Отрицательных: " << negative_count << "\n";
    return 0;
}
```

### Задание 6 **(3)**

*Представим, что в некотором будущем стандарте* **С++** *появится конструкция*
```
forc(i, from, to)
```
*которая будет раскрываться в следующий код.*
```
{
   int __i = from, __n=to;
   for(const int &i= __i; i < __n; __i++) {
      ...
   }
}
```
*Чем эта конструкция отличается от стандартного цикла* **for**? *Укажите два основных различия.
Напишите программы для демонстрации этих различий.*

*Написанные программы сохраните в папку с номером задания.*
```
#include <iostream>

int main() {
    forc(i, 0, 5) {
        std::cout << i << " ";
        i++;
    }
    for (int i = 0; i < 5; ++i) {
        std::cout << i << " ";
        i++; 
    }
    return 0;
}
```
```
#include <iostream>

int main() {
    int limit = 5;
    std::cout << "Стандартный for:\n";
    for (int i = 0; i < limit; ++i) {
        std::cout << i << " ";
        limit = 2; 
    }
    std::cout << "\n";

    limit = 5;
    std::cout << "С forc:\n";
    {
        int __i = 0;
        int __n = limit;
        for (const int &i = __i; i < __n; ++i) {
            std::cout << i << " ";
            limit = 2;
        }
    }
    std::cout << "\n";

    return 0;
}
```

1.Счетчик i доступен только для чтения (константа).
В развертке forc переменная объявлена как const int &i. Внутри цикла её нельзя изменить (нельзя сделать i++ или i = 5), иначе будет ошибка компиляции. В обычном for счетчик можно менять как угодно.

2.Границы цикла фиксируются в момент старта (работа с копиями).
В развертке создаются локальные копии __i = from и __n = to. Если внутри цикла изменить внешнюю переменную, которая передавалась в to, это не повлияет на условие выхода i < __n. В стандартном for изменение внешней границы сразу влияет на завершение цикла.

*Программа должна использовать конструкцию* **for break else**.

*Запишите аналогичную программу на С++. Какие изменения в алгоритме решения в ней появились?. Почему?*

*Написанные программы сохраните в папку с номером задания.*
```
numbers = list(map(int, input().split()))
for num in numbers:
    if num < 0:
        print("Найдено отрицательное число:", num)
        break
else:
    print("Все числа неотрицательные")
```
```
#include <iostream>
#include <vector>

int main() {
    std::vector<int> numbers;
    int num;
    while (std::cin >> num) {
        numbers.push_back(num);
    }
    bool found_negative = false;
    for (int n : numbers) {
        if (n < 0) {
            std::cout << "Найдено отрицательное число: " << n << "\n";
            found_negative = true;
            break;
        }
    }
    if (!found_negative) {
        std::cout << "Все числа неотрицательные\n";
    }
    return 0;
}
```
Изменение: Пришлось добавить логическую переменную-флаг (found), которая меняет значение на true, если находится отрицательное число. После цикла проверяется эта переменная.
Почему: В Python блок else срабатывает только при "естественном" завершении цикла (без break). В C++ цикл не может сам сообщить, прервался он или дошел до конца, поэтому это состояние нужно сохранять вручную в переменной.
