### Задание 1 **(3)**
*Рассмотрим следующую программу на С++.*
```
#include <iostream>
#include <cmath>
int main() {
   double x = 0;
   const auto Pi = std::acos(0) * 2;
   std::cout << Pi << std::endl;
   return 0;
}
```
*Проверьте четыре способа объявления* **Pi**.
* ```const auto Pi = acos(0) * 2;```
* ```constexpr auto Pi = std::acos(0) * 2;```
* ```const auto Pi = acos(x) * 2;```
* ```constexpr auto Pi = std::acos(x) * 2;```

*Что можно сказать об этих вариантах? Проверьте, в каких вариантах объявляется константа этапа трасляции.*

*Тексты программ разместите в папке с номером задания*

1. const auto Pi = acos(0) * 2;  — обычный константный объект. Значение нельзя менять через Pi, но это не гарантирует вычисление на этапе компиляции.

2. constexpr auto Pi = std::acos(0) * 2; — Ошибка компиляции. std::acos нельзя вычислить на этапе трансляции.

3. const auto Pi = acos(x) * 2; — Компилируется. Вычисляется в рантайме (из-за переменной x).

4. constexpr auto Pi = std::acos(x) * 2; — Ошибка компиляции. x не константа, и acos не constexpr.

### Задание 2 **(2)**
*Проверьте работу следующей программы на С++*
```
#include <iostream>
int main() {
   {
      int x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   {
      double x, y;
      std::cin >> x >> y;
      std::cout << x+y << std::endl;
   }
   return 0;
}
```
*Нужны ли в этой программе вложенные фигурные скобки? Дайте подробный ответ с объяснением причин.*


Вложенные фигурные скобки здесь нужны для разграничения областей видимости. Поскольку в первом блоке переменные x и y объявлены как int, а во втором - как double, в одной области видимости это сделать невозможно (компилятор выдаст ошибку повторного объявления). Фигурные скобки создают отдельные локальные блоки: при выходе из первого блока его переменные уничтожаются, поэтому во втором блоке мы можем спокойно объявить новые переменные с теми же именами, но другим типом. Без этих скобок пришлось бы придумывать переменным разные имена.


### Задание 3 **(2)**
*Проверьте работу следующего фрагмента программы на С++.*
```
int s = 0;
for (int i = 0; i < 4; i++) {
   for (int i = 0; i < 3; i++) {
      s += i;
   } 
   s += i; 
}
std::cout << s;
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

результат - 18

Внутренний цикл при каждой итерации внешнего прибавляет к s сумму 0+1+2 = 3. Поскольку во внутреннем цикле объявлена своя локальная переменная i, она не влияет на внешнюю i. После завершения внутреннего цикла к s прибавляется значение внешней i (0, 1, 2 и 3). Итоговое вычисление: (3+0) + (3+1) + (3+2) + (3+3) = 18.



### Задание 4 **(2)**

*Проверьте работу следующего фрагмента программы на* **Python**.
```
s = 0
for i in range(4):
   for i in range(3):
      s += i
   s += i
print(s)
```
*В результате каких вычислений был получен ответ? Дайте подробный ответ.*

*На основе этих примеров поясните различия между* **С++** и **Python** *при работе с переменными*.

результат - 20

Внешний цикл выполняется 4 раза. При каждой итерации внутренний цикл прибавляет к s значения 0, 1 и 2, то есть сумму 3. После завершения внутреннего цикла команда s += i дополнительно прибавляет 2, поскольку внутренний цикл оставляет переменную i равной 2. Таким образом, за каждую итерацию внешнего цикла прибавляется 3 + 2 = 5. Всего получаем 5 * 4 = 20. В Python вложенные циклы могут использовать одну переменную, поэтому внутренний цикл изменяет значение i, используемое после его завершения.

### Задание 6 **(2)**

*Рассмотрим следующий фрагмент программы. Эта программа 1000000 раз обменивает значения двух длинных 
строк с использованием третьей строки. Проверьте, насколько быстро она работает.*

```
std::string a(100000, 'a');
std::string b(100000, 'b');
for (int i=0;i<1000000;i++) {
   std::string c(a);
   a = b;
   b = c;
}
std::cout << a[0] << b[0];
```
*Попробуйте использовать для обмена значений строк функцию* **swap**. 
*Проверьте, изменилось ли время работы. В чем ошибка исходной программы?
Исправьте исходную программу, чтобы ускорить ее работу. Изменения не должны 
затрагивать общий вид программы (присваивания, использование временной переменной).*

В исходной программе строки копируются при каждой итерации, что замедляет работу. Для ускорения достаточно заменить ручной обмен значениями на функцию swap(), которая меняет строки местами без полного копирования их содержимого. Исправленный код:

```
#include <iostream>
#include <string>
using namespace std;

int main() {
    string a(100000, 'a');
    string b(100000, 'b');

    for (int i = 0; i < 1000000; i++) {
        swap(a, b);
    }

    cout << a[0] << b[0];
    return 0;
}
```
Функция swap() значительно ускоряет обмен строками, поскольку обычно меняет местами внутренние ресурсы строк, а не копирует все символы. Исходная программа тратит много времени на создание временной строки c и копирование содержимого a и b миллион раз. Исправление не меняет общий вид программы и не требует дополнительной переменной.

### Задание 7 **(2)**

*Рассмотрим программу на языке* **Python**.
```
a = 'Hello world'
print(a, id(a))
b = a
print(b, id(b))
a += ' and goodbye'
print(a, id(a))
print(b, id(b))
```
*Объясните ее работу. В какой момент создавались строки? 
Что означает значение, возвращенное функцией* **id**?

Строка 'Hello world' создаётся при присваивании a = 'Hello world'. Функция id() возвращает уникальный идентификатор объекта в памяти. После команды b = a обе переменные ссылаются на одну строку, поэтому id(a) и id(b) одинаковы. При выполнении a += ' and goodbye' создаётся новая строка, поскольку строки в Python неизменяемы. Переменная a начинает ссылаться на новую строку, а b продолжает ссылаться на старую. Поэтому идентификаторы a и b после этой операции различаются.
