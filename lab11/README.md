### Задание 2 **(1)**

*Функция* **dswap** *должна была обменивать значения своих параметров.* 
*(На выводе должно было получиться* ```3.4 1.5```.)
*В чем ошибка при написании этой функции? Как ее исправить? 
Что передавалось в параметры у исходной функции и у исправленной?* 
```
#include <iostream>
void dswap(double x, double y) {
   double t = x;
   x = y;
   y = t;
}
int main(void) {
   double x = 1.5, y = 3.4;
   dswap(x, y);
   std::cout << x << " " << y << std::endl;
   return 0;
}
```

Ошибка заключается в том, что аргументы передаются в функцию по значению, а не по ссылке (или через указатели), поэтому меняются только локальные копии переменных.

Как её исправить?
Нужно изменить сигнатуру функции так, чтобы она принимала параметры по ссылке (добавить амперсанд & к типу параметров):

```
#include <iostream>

void dswap(double &x, double &y) {
    double t = x;
    x = y;
    y = t;
}

int main(void) {
    double x = 1.5, y = 3.4;
    dswap(x, y);
    std::cout << x << " " << y << std::endl; // Выведет: 3.4 1.5
    return 0;
}
```

### Задание 3 **(3)**

*Известно, что функция* **dosome** *не изменяет значений вектора* **V**.
*Какие из способов объявления функции является правильным с точки зрения 
корректности работы программы? В чем разница между этими способами?*



```
void dosome(const vector<int> &V);
void dosome(vector<int> &V);
void dosome(const vector<int> V);
void dosome(vector<int> V);
```

• const vector<int> &V — лучший выбор: не копирует вектор (быстро) и защищает его от изменений.
• vector<int> &V — не копирует, но нет защиты от изменений и нельзя передать константный вектор.
• const vector<int> V — создаёт полную копию вектора (медленно), защищая от изменений только её.
• vector<int> V — создаёт полную копию вектора (медленно), изменения затронут только копию.

*Проверьте в какие из этих функций можно передать константные вектора. ОЛбъясните результат.*
```
dosome({1, 2, 3});
```

Для обычного вектора все четыре варианта вернут одинаковый результат (например, 15), но отличаются работой с памятью (& — без копии) и защитой данных (const — запрет на изменение). Лучший выбор для чтения — const vector<int>&: он не тратит время и память на копирование, защищает данные от случайных правок и универсален (принимает обычные, константные и временные векторы вроде {1, 2, 3}). Вариант vector<int>& тоже не создаёт копию, но разрешает менять оригинал, из-за чего не принимает константные и временные объекты (будет ошибка компиляции). Способы без ссылки (const vector<int> и vector<int>) работают с любыми векторами и не портят оригинал, но проигрывают в скорости, так как создают в памяти полную копию вектора (защищённую или изменяемую соответственно).

```

double &choose(double &a, bool flg) {
```

### Задание 8 **(3)**

*Объясните работу приведенной ниже программы.
Какие ошибки в ней имеются? (Виды ошибок смотрите в лекции.)*
```
#include <iostream>
int main() {
    int *p = new int [10];
    int *q = new int [10];
    for (int i = 0; i <= 10; i++)
        p[i] = i;
    q = p;
    delete[] p;
    for (int i = 0; i <= 10; i++)
        std::cout << q[i] <<" ";
    delete[] q;
    return 0;
}
```
Программа выделяет два динамических массива в куче, пытается заполнить и вывести первый из них, но содержит 4 классические ошибки работы с памятью, приводящие к неопределённому поведению (UB) и аварийному завершению.

ошибки:

1. Выход за границы массива (Buffer Overflow): в обоих циклах условие i <= 10 обращается к несуществующему 11-му элементу (p и q, допустимы индексы 0..9).
2. Утечка памяти (Memory Leak): строка q = p; перезаписывает указатель q, из-за чего адрес второго выделенного массива теряется и его невозможно освободить.
3. Использование после освобождения / висячий указатель (Use-After-Free / Dangling Pointer): после delete[] p; указатель q ссылается на уже освобождённую память, но цикл в следующей строке читает из неё данные (q[i]).
4. Двойное освобождение памяти (Double Free): delete[] q; пытается повторно очистить ту же область памяти, что и delete[] p;, разрушая структуру кучи.
