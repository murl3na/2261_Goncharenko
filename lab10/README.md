### Задание 4 **(2)**

*Выпишите значения всех переменных, в том числе указателей,
после выполнения каждой инструкции программы. Объясните, что

```
unsigned a = 8, b = 3 ,c = 17;
unsigned *p = &a;
unsigned *q = &b;
*p += *q + c;
c = *q;
p = &c;
c += a;
*p += 10;
*q = *p;
q = p ;
*q += 10;
```

Начальные значения: a=8, b=3, c=17

p = &a; p->a; указатель на a

q = &b; q->b; указатель на b

*p += *q + c; a=28; a = 8 + 3 + 17

c = *q; c=3; c получает значение b

p = &c; p→c; p теперь указывает на c

c += a; c=31; 3 + 28

*p += 10; c=41; p указывает на c

*q = *p; b=41; значение c записано в b

q = p; 1q->c; q тоже указывает на c

*q += 10; c=51; 41 + 10

Итог: a=28, b=41, c=51, p и q указывают на c.

### Задание 5 **(1)**

*Что сравнивается в приведенной ниже программе? Как можно
изменить первую строчку программы, чтобы результат тоже
изменился?*
```
int x = 1, y = 2;
int *p = &y, *q = &x;
if (p < q)
    std::cout << "Yes";
else
    std::cout << "No";
```

p хранит адрес y, q адрес x. Поэтому p<q сравнивает расположение переменных в памяти, а не числа 2 и 1. Замена самих значений x и y на результат сравнения адресов не влияет. Можно поменять порядок объявлений:

```
int y = 2, x = 1;
```
При проверке это изменило расположение переменных: вместо Yes получилось No.

### Задание 6 **(2)**

*Объясните работу следующей программы. Как изменится
результат, если тип* **double** *изменить на некоторый другой, например*
**int** *или* **char**?
```
double x = 0;
double *d = &x;
std::cout << reinterpret_cast<size_t>(d + 4) - reinterpret_cast<size_t>(d - 4) << std::endl;
```

Операции d + 4 и d - 4 сдвигают адрес на 4 элемента вперед и назад, поэтому разность их числовых значений (через size_t) равна 8 * sizeof(тип) байт (double - 64, int - 32, char - 8). Чтобы сдвиги не выходили за границы памяти одиночной переменной, проверку нужно проводить на массиве с указателем на его середину.

### Задание 7 **(2)**

*Объясните работу следующей программы. Как изменится
результат, если тип* **double** *изменить на некоторый другой, например*
**int** *или* **char**?
```
std::cout << reinterpret_cast <double*>(3000) - reinterpret_cast <double*>(2000) << std::endl;
```

Чтобы найти разницу между указателями, разность их адресов делится на размер типа: для double это 1000 / 8 = 125, для int - 1000 / 4 = 250, а для char - 1000 / 1 = 1000. Но так как по стандарту вычитать можно только указатели внутри одного массива, использование случайных адресов вызывает неопределенное поведение, и полагаться на эти числа нельзя.

*Что надо дописать в записанной ниже программе вместо многоточий, чтобы
она выводила все числа из массива* **a**? *Почему?*
```
int a[20];

    a[i] = i;
```

```
#include <iostream>

int main() {
    int a[20];
    for ( int i = 0; i < 20; i++)
        a[i] = i;
    int *b=a + 8;
    for (int i = -8; i < 12; i++)
        std::cout << b[i] <<' ';
    return 0;
}
```
Указатель b инициализирован как a + 8, то есть он указывает на элемент с индексом 8. Массив a состоит из 20 элементов. Чтобы вывести весь массив с помощью указателя b, нужно обращаться к элементам с отрицательными индексами и положительными. Начало массива a[0] относительно b находится по индексу -8, а конец a[19] — по индексу 11. Поэтому переменная i должна начинаться с -8 и идти до 11.

### Задание 9 **(2)**

*Что выводит следующая программа? Изменится ли результат если
изменить тип элементов массива?*

```
int a[10];
std::cout << &a[8] - &a[3] << std::endl;
```
Программа выведет число 5, и результат не изменится при смене типа элементов массива. В C++ вычитание двух указателей одного массива возвращает количество элементов между ними (\(8 - 3 = 5\)), а не разницу в байтах, так как компилятор автоматически делит разность адресов в памяти на размер одного элемента (sizeof).
