### Задание 1 **(2)**
*Переведите в двоичную запись два произвольных рациональных числа (числа вида* $\frac{p}{q}$).
*У одного из чисел знаменатель должен быть степенью двойки (32), а у другого --- некоторым числом
от 9 до 12.*

*Запись второго числа будет содержать период. Его надо найти. При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

Возьмём числа 3/32 и 1/10.

Решение 1:
* 3/32 * 2 = 3/16 -> 0;
* 3/16 * 2 = 3/8 -> 0;
* 3/8 * 2 = 3/4 -> 0;
* 3/4 * 2 = 1,5 -> 1;
оставшаяся дробная часть 0,5: 0,5 * 2 = 1,0 -> 1.
Получаем: 3/32 = 0,00011₂.
 
Решение 2:
Знаменатель 10 не является степенью двойки, значит, дробь будет периодической. Будем умножать числитель на 2 и сравнивать с знаменателем 10.

* 1⋅2=2 → 0, остаток 2
* 2⋅2=4 → 0, остаток 4
* 4⋅2=8 → 0, остаток 8
* 8⋅2=16 → 1, остаток 16−10=6
* 6⋅2=12 → 1, остаток 12−10=2

Остаток 2 повторился. Значит, дальше цифры пойдут по кругу.

Ответ:

1/10=0.0(0011)₂.

### Задание 2 **(3)**
*Переведите в двоичную запись и найдите машинное представление в типе* **double**
*для произвольного вещественного числа большего, чем 100 с одним знаком после точки, например
для* $113.7$. *Цифра после точки не должна быть нулем иля пятеркой.*

*При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

113.7

Целая часть: 113 = 64 + 32 + 16 + 1, значит 113 = 1110001₂.

Дробная часть 0.7:
* 0.7 * 2 = 1.4 -> бит 1, остаток 0.4;
* 0.4 * 2 = 0.8 -> бит 0, остаток 0.8;
* 0.8 * 2 = 1.6 -> бит 1, остаток 0.6;
* 0.6 * 2 = 1.2 -> бит 1, остаток 0.2;
* 0.2 * 2 = 0.4 -> бит 0.

Остаток 0.4 повторился, значит дальше циклически повторяются биты 0110. Получаем:

113.7 = 1110001,101100110110...₂ = 1,110001101100110011001100110011001100110011001100110...₂ * 2⁶.

Для double отводится 1 бит знака, 11 бит порядка и 52 бита мантиссы. Число положительное, поэтому бит знака равен 0. Смещение порядка равно 1023, сохранённый порядок: 6 + 1023 = 1029 = (10000000101)₂.

Первые 52 бита после ведущей единицы мантиссы с учётом округления:

1100011011001100110011001100110011001100110011001100

Итоговое представление double:

0 10000000101 1100011011001100110011001100110011001100110011001100

Дробь 0.7 имеет бесконечную двоичную запись, поэтому в double она хранится приближённо. Последний сохранённый бит учитывает округление до ближайшего представимого числа.

### Задание 3 **(3)**
*Найдите сумму и произведение для записанных далее пар чисел. Числа заданы в двоичной записи 
в экспоненциальном виде. Ответ необходимо записать в нормализованннои экспоненциальном виде.*

* 1.0011e18 и $1.1001e21;
* 1.1011e-25 и, $1.1101e-23;
* 1.1011e-3 и $1.1011e1.
  
*При решении задачи нельзя 
использовать вычислительную технику. Процесс решения должен быть представлен в отчете.*

1) 1.0011e18 и 1.1001e21

Сумма: 1.0011·2^18 = 0.0010011·2^21

  1.1001000
+ 0.0010011
-----------
  1.1011011

Ответ: 1.1011011e21

Произведение: 10011 × 11001 = 111011011 (19 · 25 = 475), 8 знаков после запятой → 1.11011011, порядок 18 + 21 = 39.

Ответ: 1.11011011e39

2) 1.1011e-25 и 1.1101e-23

Сумма: 1.1011·2^-25 = 0.011011·2^-23

  1.110100
+ 0.011011
----------
 10.001111

10.001111e-23 → нормализация (сдвиг вправо на 1, порядок +1).

Ответ: 1.0001111e-22

Произведение: 11011 × 11101 = 1100001111 (27 · 29 = 783) → 11.00001111, порядок −25 + (−23) = −48. Нормализация: 1.100001111, порядок −47.

Ответ: 1.100001111e-47

3) 1.1011e-3 и 1.1011e1

Сумма: 1.1011·2^-3 = 0.00011011·2^1

  1.10110000
+ 0.00011011
------------
  1.11001011

Ответ: 1.11001011e1

Произведение: 11011 × 11011 = 1011011001 (27 · 27 = 729) → 10.11011001, порядок −3 + 1 = −2. Нормализация: 1.011011001, порядок −1.

Ответ: 1.011011001e-1

Итог
Сумма: 1.1011011e21, произведение: 1.11011011e39
Сумма: 1.0001111e-22, произведение: 1.100001111e-47
Сумма: 1.11001011e1, произведение: 1.011011001e-1

Проверка: 19·25 = 475, 27·29 = 783, 27·27 = 729 (десятичные значения совпадают с двоичными произведениями). Округление не применялось.
